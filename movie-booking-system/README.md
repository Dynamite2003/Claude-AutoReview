# 电影选座系统

一个功能完整的纯前端电影选座系统，使用 HTML5 + CSS3 + JavaScript 实现。

## 功能特性

### 🎬 核心功能
- **电影选择**: 展示正在热映的电影信息
- **场次选择**: 选择合适的观影时间和影厅
- **智能选座**: 支持多种座位类型，智能推荐最佳座位
- **订单管理**: 完整的订单流程和历史记录
- **支付模拟**: 模拟支付宝、微信、银行卡支付

### 💺 座位类型
- **普通座位**: 基础价格 ¥40
- **VIP座位**: 高级座位 ¥60 (+¥20)
- **情侣座**: 浪漫选择 ¥55 (+¥15)，必须成对选择
- **维护座位**: 不可选择

### ⏰ 超时机制
- **选座超时**: 15分钟内完成选座，否则自动释放
- **支付超时**: 15分钟内完成支付，否则自动取消
- **实时倒计时**: 动态显示剩余时间

### 📱 响应式设计
- 完全适配手机、平板、桌面设备
- 触摸友好的交互设计
- 优雅的动画效果

### 🔄 退订功能
- 支付前可随时取消
- 支付后电影开始前2小时内可申请退票
- 退票收取10%手续费

## 技术架构

### 前端技术栈
- **HTML5**: 语义化结构，无障碍设计
- **CSS3**: Grid/Flexbox布局，动画效果，响应式设计
- **JavaScript ES6+**: 面向对象编程，模块化设计

### 核心模块
- **app.js**: 主应用逻辑，页面路由管理
- **storage.js**: 本地存储管理，数据持久化
- **seat-manager.js**: 座位选择和状态管理
- **timer.js**: 超时机制和订单管理
- **utils.js**: 通用工具函数库

### 数据存储
- 使用 `localStorage` 模拟后端数据库
- 支持数据导入导出和备份
- 自动处理数据版本兼容性

## 使用方法

### 1. 打开系统
直接在浏览器中打开 `index.html` 文件

### 2. 选择电影
- 浏览当前热映电影
- 查看电影详情和时长
- 选择感兴趣的电影

### 3. 选择场次
- 查看可用场次和座位数
- 选择合适的时间和影厅

### 4. 选择座位
- 查看座位图例了解座位类型
- 点击座位进行选择（最多8个）
- 情侣座自动成对选择
- 查看价格明细

### 5. 确认支付
- 确认订单信息
- 选择支付方式
- 在15分钟内完成支付

### 6. 管理订单
- 查看订单历史
- 申请退票（符合条件时）
- 查看订单详情

## 快捷键

- **ESC**: 返回上一页
- **1-8**: 在选座页面快速选择对应数量座位
- **Ctrl+Enter**: 快速确认当前操作

## 注意事项

⚠️ **重要提醒**: 这是一个纯前端演示系统，具有以下限制：

1. **数据同步**: 无法实现多用户间的实时数据同步
2. **并发处理**: 多用户同时选座可能出现冲突
3. **数据持久性**: 清除浏览器缓存会丢失所有数据
4. **支付安全**: 仅为模拟支付，无真实支付功能
